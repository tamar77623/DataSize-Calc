A clean, responsive, and lightweight web application built to convert **Data Storage Units** ($MB \leftrightarrow GB \leftrightarrow TB$) instantly and calculate **Actual Internet Download Speeds** ($Mbps \to MB/s$).

---

## ✨ Features

- **⚡ Instant Real-time Conversion:** Performs math logic automatically as you type without reloading.
- **💾 Storage Unit Converter:** Converts values across Megabytes ($MB$), Gigabytes ($GB$), and Terabytes ($TB$).
- **🌐 Internet Speed Calculator:** Converts ISP speed ($Mbps$) into actual download performance ($MB/s$).
- **🎨 Modern UI/UX:** Styled with clean dark-mode gradients, smooth hover interactions, and standard accessibility rules.
- **📱 Fully Responsive:** Works seamlessly on desktop, tablet, and mobile screens.

---

## 🧮 Math Formulas Used

### 1️⃣ Data Storage
Based on binary byte logic ($1 \text{ GB} = 1024 \text{ MB}$):
- $\text{GB} = \text{MB} \div 1024$
- $\text{TB} = \text{GB} \div 1024 = \text{MB} \div (1024 \times 1024)$

### 2️⃣ Internet Speed
Based on the $1 \text{ Byte} = 8 \text{ Bits}$ rule:
- $\text{Actual Download Speed (MB/s)} = \text{ISP Speed (Mbps)} \div 8$
